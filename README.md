# Dad Joke Showdown

[![Reward](https://make.fun/badge/u-mfnakmal-dad-joke-showdown-1d2ce3e5/Rahul7039/dad-joke-showdown/reward.svg)](https://make.fun/c/u-mfnakmal-dad-joke-showdown-1d2ce3e5)

One original dad joke, written to be told out loud at the dinner table: a father tells his son the money in their savings account is growing, the boy asks when they can pick it, and the punchline lands on "interest takes time" — a double turn on *interest* (money growth and curiosity) and on *takes time* (needs patience, and literally accrues over time). Six candidates were drafted and scored against the judge's brief (dad-ness, clean first-read pun, freshness, tightness, aloud rhythm); this one won for its original scenario and its clean double pun. The program validates the line against the competition gate (UTF-8, 1–200 characters, not only white space) and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3 with only the standard library. The script prints the character count and verifies the written file byte for byte before exiting.
